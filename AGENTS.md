# Інструкції для ШІ-асистентів у цьому репозиторії

Цей файл читають агенти для коду (Codex, GitHub Copilot, Cursor, Gemini CLI
та інші — перелік на https://agents.md). Людям він теж корисний: це коротка
пам'ятка, як тут усе влаштовано. Заняття 15 пояснює, навіщо такий файл.

## Що це за репозиторій

Навчальний кластер Amazon EKS для курсу DevOps. Учасники — початківці.
Регіон — `eu-central-1`. Акаунти AWS на Free plan: дозволені лише деякі
типи машин, див. розділ «Що змінилося після заняття 8» у `README.md`.

- `cluster/` — уся конфігурація Terraform, один воркспейс HCP Terraform.
- `lessons/NN-*/` — файли, які копіюють у `cluster/` по мірі курсу.
- `apps/`, `infrastructure/` — маніфести, які розгортає Flux.
- `charts/shop/` — Helm-чарт застосунку.
- `docs/lesson-NN.md` — покрокові інструкції занять.

## Правила

1. **Нічого не застосовуй сам.** Не запускай `terraform apply`, `terraform destroy`,
   `kubectl apply`, `kubectl delete`, `helm install/uninstall`. Пропонуй команду
   й пояснюй, що вона змінить; запускає людина.
2. **Перевіряй, а не вгадуй.** Після змін у Terraform — `terraform fmt` і
   `terraform validate`. Аргументи ресурсів і модулів звіряй з документацією
   провайдера саме тієї версії, що в `cluster/versions.tf`.
3. **Жодних секретів у git.** Не додавай у файли ключі, паролі, токени,
   `terraform.tfvars`. Секрети застосунку живуть у Parameter Store і приходять
   через External Secrets Operator (заняття 10).
4. **Гроші.** Не пропонуй NAT Gateway, балансувальники «про всяк випадок»,
   типи машин поза Free plan. Якщо зміна коштує грошей — скажи це прямо.
5. **Мова.** Коментарі в коді й пояснення — українською, просто, для
   початківця. Кожне свідоме спрощення познач коментарем: як це роблять у
   продакшні.
6. **Не знаєш — скажи.** Краще «не впевнений, перевірте в документації», ніж
   правдоподібна вигадка.
